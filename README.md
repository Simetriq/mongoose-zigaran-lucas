Durante el desarrollo del trabajo se eligio utilizar el formato referenciado para realizar las relaciones por ser la opcion mas eficiente.

Se debe utilizar referenciado cuando:

✅ CUANDO LOS DATOS PUEDEN CRECER MUCHO 
✅ CUANDO LAS ENTIDADES SON INDEPENDIENTES
 Ejemplo: Categorías que existen por sí mismas
✅ CUANDO NECESITAS CONSULTAR LAS ENTIDADES POR SEPARADO

Se debe utilizar embebido cuando: 
 ✅ CUANDO LOS DATOS NO TIENEN RAZÓN PARA EXISTIR POR SEPARADO
 ✅ PARA DATOS QUE SIEMPRE SE ACCEDEN JUNTOS
 ✅ PARA MEJOR RENDIMIENTO EN LECTURAS
    Una sola consulta trae todos los datos
